PRIVACY BY DESIGN
Designed to keep your data yours.
List definitions and formatting are generated directly in your browser. Your workspace is saved in your browser's local storage for convenience. There is no account, tracking pixel, or application analytics. The online version loads shared Mightora assets from external hosts; the offline edition does not.
Network transparency & verification
Use F12 → Developer Tools → Network → Preserve log, then reload to inspect every request. The browser's Performance Resource Timing view can omit some information, so developer tools or an independent audit are more complete.
